# ERL-Governed Research Surface

This layer sits beside FREE-DOM's existing AI Search Agent and evidence/privacy machinery. It does not replace native verified/master datasets, native source health, privacy rules, or existing search-run evidence.

ERL-governed trajectories are stored under `research/`. The ERL-specific adapter searches configured public sources and emits only `lead-only` candidates. ERL remains evaluation authority for ERL-linked propositions. FREE-DOM remains authority for its native privacy/anonymity and record-management rules.

All ACTIVE trajectories must be searched without a binary support/refute assumption. Contradictory, null, mixed, and newly discovered trajectories are preserved. GitHub tokens are not research/evaluation authority; TV/TVC governs credentials where applicable.
